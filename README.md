# Hackpad
Cutom keypad for the stardance hackpad challenge


My hackpad has 5 keys, a rotary encoder, a led status bar and an oled display. It uses QMK firmware.

## BOM
For this project I used:

* 5x Cherry MX Switches
* 5x DSA Keycaps
* 6x 1N4148 DO-35 Diodes
* 6x SK6812 MINI-E LEDs
* 1x 0.91" 128x32 OLED Display
* 1x EC11 Rotary Encoder
* 1x XIAO RP2040
* 1x Case (2 3d printed parts)
